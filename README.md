# Movie Search System (Sakila Database)

Консольное приложение для поиска фильмов в базе данных Sakila с логированием запросов в MongoDB.

## Описание проекта

Система поиска фильмов, которая позволяет:
- Искать фильмы по ключевому слову в названии
- Фильтровать фильмы по жанру и диапазону годов
- Просматривать популярные и последние поисковые запросы
- Логировать все запросы для последующего анализа

## Технологии

- **Python 3.x**
- **MySQL** - база данных Sakila с информацией о фильмах
- **MongoDB** - хранение логов поисковых запросов
- **PyMySQL** - подключение к MySQL
- **PyMongo** - подключение к MongoDB
- **python-dotenv** - управление переменными окружения
- **tabulate** - форматирование таблиц в консоли

## Установка и настройка

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd project
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Настройка базы данных MySQL

Убедитесь, что установлена база данных Sakila:

```bash
# Скачайте и импортируйте Sakila DB
# https://dev.mysql.com/doc/sakila/en/
mysql -u root -p < sakila-schema.sql
mysql -u root -p < sakila-data.sql
```

### 4. Настройка MongoDB

Установите и запустите MongoDB:

```bash
# Windows
mongod --dbpath C:\data\db

# Linux/Mac
mongod --dbpath /data/db
```

### 5. Настройка переменных окружения

Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

Отредактируйте `.env` и укажите ваши данные:

```env
# MySQL Configuration
MYSQL_HOST=localhost
MYSQL_USER=root
MYSQL_PASSWORD=your_password
MYSQL_DATABASE=sakila
MYSQL_CHARSET=utf8mb4

# MongoDB Configuration
MONGO_HOST=localhost
MONGO_PORT=27017
MONGO_DATABASE=movie_search
MONGO_COLLECTION=final_project_121225-ptm_maxim_kravchenko
```

## Функционал

### 1. Поиск по ключевому слову

Позволяет искать фильмы по части названия. Результаты выводятся постранично (10 фильмов на страницу).

**Пример:**
```
Введите ключевое слово для поиска: love
```

### 2. Поиск по жанру и диапазону годов

Позволяет фильтровать фильмы по жанру и годам выпуска.

**Пример:**
```
Введите название жанра: Action
Введите год ОТ: 2000
Введите год ДО: 2010
```

### 3. Популярные запросы

Показывает топ-5 наиболее часто выполняемых поисковых запросов.

### 4. Последние запросы

Показывает последние 5 выполненных поисковых запросов с временными метками.

## Структура данных

### MySQL (Sakila)

Используются следующие таблицы:
- `film` - информация о фильмах
- `category` - жанры фильмов
- `film_category` - связь фильмов и жанров

### MongoDB (Логи)

Формат документа лога:

```json
{
  "search_type": "keyword",
  "parameters": {
    "keyword": "love"
  },
  "results_count": 15,
  "timestamp": "2024-12-12T10:30:00Z"
}
```

## Модули

### main.py
Главная точка входа приложения. Содержит:
- Меню навигации
- Обработку пользовательского ввода
- Пагинацию результатов

### mysql_connector.py
Функции для работы с MySQL:
- `search_by_keyword(keyword, offset)` - поиск по ключевому слову
- `search_by_genre_and_year(genre, year_from, year_to, offset)` - поиск по жанру и годам
- `get_all_genres()` - получение списка всех жанров
- `get_year_range()` - получение диапазона годов в БД

### log_writer.py
Логирование поисковых запросов в MongoDB:
- `log_search(search_type, parameters, results_count)` - запись лога

### log_stats.py
Получение статистики из MongoDB:
- `get_popular_searches(limit)` - популярные запросы
- `get_recent_searches(limit)` - последние запросы

### formatter.py
Форматирование вывода данных:
- `format_movies(movies)` - форматирование списка фильмов
- `format_popular_searches(searches)` - форматирование популярных запросов
- `format_recent_searches(searches)` - форматирование последних запросов
- `format_genres(genres)` - форматирование списка жанров

## Особенности реализации

- **Пагинация**: результаты выводятся по 10 записей с возможностью загрузки следующей страницы
- **Валидация ввода**: проверка корректности введенных данных (годы, жанры)
- **Обработка ошибок**: graceful handling подключений к БД и пользовательского ввода
- **Логирование**: все запросы сохраняются в MongoDB для анализа
- **Форматированный вывод**: использование tabulate для красивого отображения таблиц
