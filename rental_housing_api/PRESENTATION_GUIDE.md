## 📋 ЧТО ГОВОРИТЬ ПРЕПОДАВАТЕЛЮ

### 1. Описание проекта (1-2 минуты)

**Скажи:**
> "Я разработал backend для платформы краткосрочной аренды жилья - аналог Airbnb. Это RESTful API на Django REST Framework с полной функциональностью: регистрация пользователей, создание объявлений, система бронирования с валидацией дат, отзывы и аналитика."

### 2. Технологии (30 секунд)

**Скажи:**
> "В проекте использованы:
> - **Django 4.2** и **Django REST Framework** - для backend
> - **JWT токены** для безопасной аутентификации
> - **MySQL** в качестве базы данных
> - **Docker** и **Docker Compose** для контейнеризации
> - **Swagger/OpenAPI** для автоматической документации API"

### 3. Функционал (1 минута)

**Скажи:**
> "Реализованы две роли пользователей:
> - **Арендодатели** могут создавать объявления, загружать фото, управлять бронированиями
> - **Арендаторы** могут искать жильё с фильтрами, бронировать и оставлять отзывы
> 
> Система автоматически проверяет пересечение дат, рассчитывает стоимость, обновляет рейтинги и ведёт аналитику просмотров."

## 💻 КАК ЗАПУСТИТЬ ДЛЯ ДЕМОНСТРАЦИИ

### Вариант 1: Локально (БЕЗ Docker - БЫСТРЕЕ)

**За 2 минуты до демонстрации:**

```bash
# 1. Открой PowerShell в папке проекта
cd C:\project\rental_housing_api

# 2. Активируй виртуальное окружение
.\.venv\Scripts\activate

# 3. Убедись что .env настроен для SQLite
# Файл .env должен содержать: USE_MYSQL=False

# 4. Примени миграции (если ещё не сделано)
python manage.py migrate

# 5. ЗАПУСТИ СЕРВЕР
python manage.py runserver
```

**Готово!** Сервер запущен на `http://localhost:8000`

### Вариант 2: Через Docker (если есть время)

```bash
# 1. Открой PowerShell
cd C:\project\rental_housing_api

# 2. Запусти Docker Compose
docker-compose up -d

# 3. Дождись запуска (30-60 секунд)
docker-compose logs -f web
```

**Ctrl+C** чтобы выйти из логов. API на `http://localhost:8000`

## 🎯 ЧТО ПОКАЗЫВАТЬ ПРЕПОДАВАТЕЛЮ

### 1. Swagger документация (ГЛАВНОЕ!)

**Открой в браузере:**
```
http://localhost:8000/api/docs/
```

**Скажи:**
> "Это интерактивная документация API, сгенерированная автоматически. Здесь можно протестировать все endpoints прямо в браузере."

**Покажи секции:**
- 📁 **auth** - регистрация и авторизация
- 📁 **listings** - объявления
- 📁 **bookings** - бронирования  
- 📁 **reviews** - отзывы
- 📁 **analytics** - аналитика

### 2. Демонстрация работы API

#### Шаг 1: Регистрация пользователя

В Swagger найди **POST /api/auth/register/**

Нажми **Try it out**, введи:
```json
{
  "email": "landlord@test.com",
  "password": "Test123456",
  "first_name": "Иван",
  "last_name": "Петров",
  "role": "landlord"
}
```

Нажми **Execute**. Должен вернуться **201 Created**

**Скажи:**
> "Создал арендодателя. Пароль хешируется автоматически Django."

#### Шаг 2: Получение токена

Найди **POST /api/auth/login/**

```json
{
  "email": "landlord@test.com",
  "password": "Test123456"
}
```

**Execute** → Скопируй `access` токен

**Скажи:**
> "Система выдала JWT токен. Он действует 1 час, потом нужно обновить через refresh token."

#### Шаг 3: Авторизация в Swagger

Нажми кнопку **Authorize** (зелёный замок вверху)

Введи:
```
Bearer ВАШ_ACCESS_TOKEN
```

Нажми **Authorize**, затем **Close**

**Скажи:**
> "Теперь я авторизован и могу выполнять защищённые операции."

#### Шаг 4: Создание объявления

Найди **POST /api/listings/**

```json
{
  "title": "Уютная квартира в центре Киева",
  "description": "2-комнатная квартира с видом на Крещатик",
  "housing_type": "apartment",
  "city": "Kiev",
  "address": "ул. Крещатик, 1",
  "price_per_night": 1500,
  "price_per_night_currency": "UAH",
  "max_guests": 4,
  "bedrooms": 2,
  "bathrooms": 1
}
```

**Execute** → **201 Created**

**Скажи:**
> "Объявление создано. Система автоматически привязала его к текущему пользователю и выставила is_active=True."

#### Шаг 5: Получение списка объявлений

Найди **GET /api/listings/**

Добавь фильтры в Parameters:
- `city`: Kiev
- `min_price`: 1000
- `max_price`: 2000

**Execute**

**Скажи:**
> "Система вернула список с фильтрацией. Также есть поиск по тексту и сортировка."

#### Шаг 6: Регистрация арендатора

**POST /api/auth/register/**
```json
{
  "email": "tenant@test.com",
  "password": "Test123456",
  "first_name": "Мария",
  "last_name": "Сидорова",
  "role": "tenant"
}
```

Получи токен через **POST /api/auth/login/**, авторизуйся снова.

#### Шаг 7: Создание бронирования

**POST /api/bookings/**
```json
{
  "listing": "UUID_ОБЪЯВЛЕНИЯ_ИЗ_ШАГА_4",
  "check_in": "2026-10-01",
  "check_out": "2026-10-05",
  "guests_count": 2
}
```

**Скажи:**
> "Система проверила доступность дат, рассчитала итоговую стоимость (1500 UAH × 4 ночи = 6000 UAH) и создала бронирование со статусом 'pending'."

#### Шаг 8: Админ-панель (если есть время)

Открой:
```
http://localhost:8000/admin/
```

Войди как суперпользователь (если создавал).

**Скажи:**
> "Django Admin позволяет управлять всеми данными, смотреть историю изменений благодаря django-simple-history."

## 🎤 ВОПРОСЫ ОТ ПРЕПОДАВАТЕЛЯ И ОТВЕТЫ

### "Как обеспечивается безопасность?"

**Ответ:**
> "1. JWT токены с коротким временем жизни
> 2. Хеширование паролей через PBKDF2
> 3. Permissions на уровне объектов - только владелец может редактировать
> 4. Django ORM защищает от SQL injection
> 5. CORS настройки контролируют кросс-доменные запросы"

### "Как решается проблема пересечения бронирований?"

**Ответ:**
> "Двухуровневая защита:
> 1. Валидация в serializer'е проверяет пересечение с существующими бронями
> 2. Database constraint на уровне MySQL - гарантирует целостность даже при конкурентных запросах"

### "Почему выбрали Django REST Framework?"

**Ответ:**
> "1. Быстрая разработка благодаря встроенным ViewSets и Serializers
> 2. Автоматическая генерация OpenAPI документации
> 3. Богатая экосистема библиотек
> 4. Встроенная админ-панель Django для управления данными"

### "Как масштабировать систему?"

**Ответ:**
> "1. Docker позволяет горизонтальное масштабирование - добавить больше контейнеров
> 2. Можно добавить Redis для кеширования частых запросов
> 3. Celery для асинхронных задач (email, уведомления)
> 4. CDN для статических файлов и фотографий
> 5. Database read replicas для чтения"

### "Что бы добавили в будущем?"

**Ответ:**
> "1. Интеграция платёжных систем (Stripe)
> 2. Email уведомления при изменении статуса брони
> 3. WebSocket чат между арендодателем и арендатором
> 4. Геолокация и карты (Google Maps API)
> 5. ML рекомендации объявлений на основе истории"
